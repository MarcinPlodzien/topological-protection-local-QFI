Codes and data for the figures of
"Topological protection of local quantum Fisher information"
M. Plodzien and J. Chwedenczuk

Each FigureN/ folder is self-contained: it holds the plotted data as
plain-text files (whitespace-separated columns, '#' header describing the
content) and the Python script (numpy + matplotlib) that produces the figure:

    python make_*.py

The script reads the data files from the same folder and writes
FigureN.pdf next to them.
